SISTEMA DE GESTIÓN DE ACADEMIAS - INSTALACIÓN

1. Copie el instalador al equipo Windows de destino.
2. Ejecútelo y conserve marcada la creación del acceso directo.
3. Abra "Sistema de Gestión de Academias" desde el escritorio.
4. El navegador se abrirá automáticamente en http://127.0.0.1:5000.
5. Ingrese con la clave inicial 00000 y cámbiela inmediatamente.

Los datos se guardan en:
%LOCALAPPDATA%\GestionAcademiaDeportiva

Los documentos generados se organizan en:
%LOCALAPPDATA%\GestionAcademiaDeportiva\Descargas

El botón "Abrir Descargas" de Información general abre esa carpeta.

La desinstalación conserva esa carpeta para evitar perder alumnos, pagos,
fotografías y respaldos. Para eliminarla definitivamente, primero haga una
copia de seguridad y luego bórrela manualmente.
